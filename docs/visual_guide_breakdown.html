🛰️ The Whole Project, Explained Simply

Revision edition — every fancy term in this project, dumbed down to plain words, with the real numbers from your build. Read top to bottom (~10 min), then flip the flashcards.

The story in 8 steps

1The job: sort satellite photos into 10 bins.
A satellite took 27,000 tiny photos of Europe. Each photo shows ONE kind of land — forest, river, houses, crops… Our program's whole job: look at a photo, say which of the 10 bins it belongs in. That's it. Everything else is detail.
📖 The fancy words: image classification — photo in, label out. EuroSAT — the name of this photo collection. Sentinel-2 — the European satellite that took them.
2To a computer, a photo is just a grid of numbers.
Each photo is 64×64 tiny dots, and every dot is 3 numbers (how much red, green, blue). So one photo = 12,288 numbers. "Recognizing a forest" really means "spotting a pattern in 12,288 numbers." Hover the real grid in the 📚 Learn tab.
📖 The fancy words: pixel — one dot. tensor — the box of numbers (ours is 3×64×64). RGB channels — the red/green/blue layers.
3We didn't teach a brain from scratch — we borrowed one.
Training eyes from zero needs millions of photos and weeks of computing. Instead we took ResNet18 — a network already trained on 1.2 million everyday photos, so it already knows edges, textures, shapes — and froze it (locked its knowledge). We bolted on one tiny new final layer and taught ONLY that. Of its 11.2 million dials, we adjusted just 5,130 — 0.05%. That's why a laptop with no GPU trained it in ~7 minutes.
📖 The fancy words: transfer learning — reusing a pre-trained network. frozen backbone — the locked part. head — the small new layer we trained. pretrained weights — the borrowed knowledge.
4Teaching = guess, get corrected, adjust. Repeat 21,600 times. Three times over.
Show a photo → the model guesses → we reveal the right answer → a score says HOW wrong it was → every dial nudges a tiny bit toward less-wrong. One full pass through all training photos is an epoch; we did 3. Our wrongness score fell from 0.94 to 0.47 — that falling number IS learning.
📖 The fancy words: loss — the wrongness score. gradient descent / backpropagation — the math that decides which way to nudge each dial. optimizer (Adam) — the nudging strategy. learning rate — nudge size.
5The exam: photos it never studied.
Scoring the model on photos it trained on would be like grading students on questions they memorized. So we hid 5,400 photos (20%) during training and tested on those strangers: 85.1% correct. Anyone quoting accuracy should be asked: "on data the model saw, or never saw?"
📖 The fancy words: train/validation split — study set vs exam set. unseen data — never used for adjusting dials. generalization — doing well on strangers. overfitting — memorizing instead of learning.
6One number can lie, so we look at WHICH mistakes it makes.
A table shows truth-vs-guess for every pair of bins. Ours revealed the model mixed up River with Highway 81 times — both are long thin lines across land! And since some bins have more photos than others, we also report kappa 0.834 — a stricter score that subtracts lucky guessing (0 = guessing, 1 = perfect).
📖 The fancy words: confusion matrix — the truth-vs-guess table. Cohen's kappa — luck-corrected accuracy. class imbalance — unequal bin sizes.
7The detective check: was our exam secretly leaked?
Photos cut from the same farm look nearly identical. If one twin lands in the study set and the other in the exam, the model can "recognize the place" instead of understanding land — score inflated. So we recovered every photo's REAL map location (hidden inside the satellite files' metadata), held out whole 50 km chunks of Europe the model never saw any part of, and re-ran the exam.
📖 The fancy words: spatial autocorrelation — near things look alike. data leakage — exam answers sneaking into study. spatial cross-validation — exam by region, not by photo. GeoTIFF — image file carrying map coordinates.
8The verdict: no cheating found — and we know why.
Exam-by-region scored 85.6% vs 85.2% random — no drop, no leak. Why? Cheating-by-memorizing needs memory, and we only trained 5,130 dials — too small to memorize places. That's an honest null result, and it sets up the sequel: unlock all 11.2 million dials (Phase C) and see if the cheating appears. See the real map in the 🧪 Phase B tab.
📖 The fancy words: null result — we looked for an effect and honestly found none. model capacity — how much it CAN memorize. fine-tuning — unlocking the frozen part.

⚡ Flashcards — flip to test yourself

What does this project actually do, in one sentence?
Takes a 64×64 satellite photo and sorts it into one of 10 land-cover bins (forest, river, crops…), scoring 85% on photos it never saw.
Why could we train it on a laptop in minutes?
Transfer learning: we borrowed an already-trained ResNet18, froze its 11.2M dials, and only trained a tiny 5,130-dial final layer.
What is "loss" and what did ours do?
The wrongness score the model tries to shrink. Ours fell 0.94 → 0.47 over 3 epochs — falling loss = learning.
Why isn't accuracy alone trustworthy?
It hides WHICH mistakes happen (ours mixed River with Highway 81×) and it can be inflated by lucky guessing on imbalanced bins — that's why we also report kappa (0.834).
What is spatial leakage, in plain words?
Twin photos from the same farm landing in both study set and exam set — the model recognizes the PLACE instead of understanding the land, inflating the score.
How did we test for leakage, and what did we find?
Recovered every photo's map location from GeoTIFF metadata, held out whole 50km regions, retrained identically. Found NO gap (85.6% vs 85.2%) — our tiny trained head can't memorize places. Honest null result.
What's the one-line resume description?
"Built a satellite land-cover classifier (transfer learning, 85% on unseen data) and validated it with spatial cross-validation — recovering patch coordinates from GeoTIFF metadata to rule out leakage."
What's the Phase C cliffhanger?
Does unlocking all 11.2M parameters (fine-tuning) reopen the leakage gap? More capacity = more ability to memorize places. We predicted leakage needs memory — now we test it.
