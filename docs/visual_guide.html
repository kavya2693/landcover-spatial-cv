1 — An image is just a grid of numbers

Hover (or tap) any pixel. What you see as "colour" the model sees as three numbers: Red, Green, Blue intensity (0–255). A 64×64 EuroSAT patch = 64 × 64 × 3 = 12,288 numbers. This demo shows a simplified 16×16 "river through fields" patch.

Hover a pixel…

Interview line: "The input is a 3×64×64 tensor — classification means mapping 12,288 numbers to one of 10 labels."

2 — A convolution slides a tiny pattern-detector across the image

This is the core CNN operation. A 3×3 filter (here: a vertical-edge detector) slides across the patch. Bright output = "my pattern is HERE". Watch it light up exactly along the river's edges — that's how the network finds rivers, roads, and field boundaries.

Input image

Filter output (edges found)

ResNet18 stacks 18 layers of these: layer 1 finds edges → middle layers combine edges into textures (forest canopy, crop rows) → deep layers recognise whole concepts ("street grid" → Residential).

Interview line: "Convolutions exploit locality and translation invariance — a river edge means the same thing anywhere in the image."

3 — Transfer learning: we only trained the last layer

■ Blue layers (11.2M parameters) — pre-trained on 1.2M ImageNet photos, FROZEN (never change). ■ Orange layer (5,130 parameters) — brand new, the only thing that learned. That's 0.05% of the model — and why training took minutes on a CPU instead of days on a GPU.

Interview line: "I froze the backbone as a fixed feature extractor and trained a 512→10 linear head — strong baseline, minimal compute, hard to overfit."

Why kappa, not just accuracy? With 10 classes, blind guessing scores ~10%; always guessing the biggest class scores ~11%. Kappa rescales so 0 = chance, 1 = perfect. Your 0.834 says: "83.4% of the gap between chance and perfection has been closed." Accuracy alone can't say that.

Interview line: "Errors concentrated on semantically similar pairs — linear features and vegetation types — not random noise. That tells me the model learned real structure."

6 — The trap we set up to expose next: spatial leakage

In a random split, neighbouring patches from the same farm land in both train (blue) and validation (orange). The model partly "recognises the place" instead of "understanding cropland" — inflating the score. Click the button.

The signature finding (Phase B): re-validate with geographically separated folds, and report exactly how many points of accuracy were an illusion. This is what makes the project senior-level.

🧪 Was our 85.1% honest? The spatial test

The experiment: train the exact same model twice. Once validated on a random 20% (patches scattered between training patches — neighbours leak). Once validated on whole 50 km geographic blocks the model never saw any part of. Same epochs, same code — only the split changes. Every patch's location was recovered from the multispectral GeoTIFF metadata (tiepoint + pixel scale + UTM zone).

⏳ Experiment running on your CPU… this tab updates automatically when outputs/spatial_gap.json appears. Refresh in a few minutes.

Why this matters in interviews: anyone can report high accuracy. Reporting how much of it was a leakage illusion — with the experiment to prove it — is what separates "I trained a model" from "I evaluate models honestly."

🚀 Phase C: did capacity hide the leakage?

The cliffhanger from Phase B: with a frozen backbone, the spatial test found no leakage gap — random scored 85.2%, spatial 85.6%, basically a tie. That was suspicious in a good way.

The hypothesis: leakage needs memorisation capacity. In Phase B only 5,130 of 11.2M parameters trained — the tiny head simply can't memorise specific farms, so there was nothing to leak. A model that can memorise places should show the gap.

The experiment: Phase C unfreezes all 11.2M parameters (full fine-tuning, with a gentler learning rate on the pretrained layers so we don't destroy the ImageNet features), then re-runs the identical random-vs-spatial split — same data, same epochs, only the trainable surface changes.

Prediction to test: if the capacity hypothesis is right, the gap should REOPEN — the random split will pull ahead of the honest spatial split once the network has enough capacity to recognise places.

🤖 vs 🤖 CNN vs Transformer — the final Phase C benchmark

Same seed, same spatial folds, same training recipe — only the architecture differs. The CNN (ResNet18, 11.2M params, local sliding filters) against a Vision Transformer (ViT-tiny, 5.5M params, every image patch attends to every other). Scored with per-class IoU — harsher than accuracy because it punishes both missed detections and false alarms.
